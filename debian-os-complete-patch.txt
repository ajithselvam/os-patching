  3. Backup your APT sources
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak

Also backup extra repo files:

sudo cp -r /etc/apt/sources.list.d /etc/apt/sources.list.d.bak



  4. Replace Bullseye with Bookworm

Open sources file:

sudo nano /etc/apt/sources.list

Replace every:

bullseye

with:

bookworm




  6. Refresh package database
sudo apt update
7. Perform minimal upgrade
sudo apt upgrade --without-new-pkgs -y





  8. Perform full Debian 12 upgrade
       sudo apt full-upgrade -y
  9. Reboot into Debian 12
     sudo reboot




  11. Clean leftover packages
sudo apt --purge autoremove -y
sudo apt clean
